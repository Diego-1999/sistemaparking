# Sistema de Gestión de Parqueo Público

Este proyecto forma parte de una **tesis de grado** y tiene como objetivo el diseño e implementación de un sistema de gestión para parqueos públicos, enfocado en la digitalización de procesos y la optimización del control de espacios disponibles.

## 🎯 Objetivo
El sistema busca:
- Facilitar la administración de parqueos públicos.
- Digitalizar procesos de registro, ocupación y control de espacios.
- Proporcionar reportes claros y defendibles para análisis académico y técnico.

## 🏗️ Arquitectura
El proyecto se desarrolla bajo una **arquitectura en capas**, lo que permite una separación clara de responsabilidades y facilita la mantenibilidad del sistema:
- **Capa de Presentación**: Interfaz gráfica construida con **Windows Forms (C#)**.
- **Capa de Negocio**: Lógica de procesos y validaciones.
- **Capa de Datos**: Acceso y gestión de información mediante **SQL Server** y **ADO.NET**.

## ⚙️ Tecnologías utilizadas
- Lenguaje: **C#**
- Framework: **.NET Framework / Windows Forms**
- Base de Datos: **SQL Server**
- Control de versiones: **GitHub**

## 📊 Funcionalidades principales
- Registro y control de vehículos en el parqueo.
- Administración de espacios disponibles y ocupados.
- Generación de reportes diarios de ocupación.
- Filtros y consultas defendibles para análisis académico.

## 📚 Contexto académico
Este sistema se desarrolla como parte de una tesis universitaria, integrando conceptos de:
- Digitalización de procesos.
- Usabilidad y confiabilidad en sistemas de gestión.
- Documentación metodológica y defensa académica.
